# Bound the Browsing Window History Cache

The client will retain the active Browsing Window, including a Viewer-pinned originating window, plus only the most recently inactive Browsing Window for exact Back restoration without another Timeline or Archive collection read. The browsing history registry is the sole lifecycle owner and atomically drives each Browsing Window through active, inactive, and disposed states when history keys change; React mount or unmount does not define those states. An inactive retained window stops its Thumbnail Access scheduler, cancels renewal and collection reads, clears viewport demand, and discards all temporary Thumbnail Access; it retains compact descriptors, layout, cursor chain, restoration anchor, and every collection page that completed before deactivation. Each activation has a lifecycle generation, and a late collection or renewal settlement from another generation is ignored even if cancellation raced with response settlement. Lifecycle cancellation does not become a load failure. Connectivity loss is a distinct suspension within an active generation: it pauses collection and access work without discarding retained state or presenting cancellation as failure, then automatically re-evaluates demand when online returns. Document visibility is also not a registry lifecycle transition: hidden preserves the active generation, demand, and temporary access, admits already in-flight settlements, and suppresses only new work until visible returns. Reactivation, in contrast, restores geometry from retained structure, obtains access for the newly observed viewport in a batch, and reissues any incomplete collection read from the retained cursor only when its current viewport demand requires it. Collection reads remain serial and demand-driven after reactivation. A Viewer-pinned originating window remains active because opening its contextual Photo Viewer does not change the registry key. Older history entries keep their URL start anchor and lightweight recovery hints but recreate the window from that anchor when revisited, without promising an evicted deep scroll position. Timeline and Archive share this cache bound. This keeps browser history semantically correct while preventing repeated date jumps or collection switches from retaining multiple 20,000-Photo descriptor sets; the bound may be raised later from measured headroom without changing correctness.

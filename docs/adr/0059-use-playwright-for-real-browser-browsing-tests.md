# Use Playwright for Real-Browser Browsing Tests

Browsing tracer verification will keep pure layout and deep-module behaviour in Vitest with in-memory adapters, while `@playwright/test` covers real History, contextual Viewer routing, virtualisation, focus, responsive layout, image failures, and network races using generated intercepted API pages. A pinned Chromium project owns numeric performance gates and a 320px WebKit project provides functional smoke coverage; cross-engine heap or timing differences do not gate the same numeric budget. Traces are retained for failures rather than every passing run, and the project will not adopt Playwright's experimental component testing. This adds browser installation and CI cost in exchange for testing behaviours jsdom cannot represent.

# Use React Router with a Separate Browsing Window Controller

The web client will adopt React Router Data Mode for route matching, browser history, location state, navigation cancellation, and route-level failures. Its contextual or masked-location support will implement the stable Photo Viewer URL over a retained Timeline or Archive route, while a direct Viewer URL renders independently. Cursor pages, Justified Row layout, virtualisation, Thumbnail Access leases, and restoration anchors remain in a dedicated Browsing Window controller rather than router loader state, and the app will not introduce a custom history object or use generic pixel scroll restoration for the virtualised collection. This adds one routing dependency while avoiding a hand-built history system and keeping browsing mechanics replaceable beneath the route boundary.

# Query Viewer Neighbours from Existing Projections

Viewer bootstrap will derive the current Ready Photo's exact v2 projection sort key from its authoritative collection, active chronology, Added At, and Photo ID, then issue strongly consistent limited queries for the nearest greater and lesser keys to obtain newer and older neighbours. It will validate that the current projection still belongs to the requested collection, retry one concurrent move internally, and return a recoverable conflict if chronology or Archive membership keeps changing. The system will not persist previous/next links or add a neighbour index whose chain would require multi-item rewrites whenever a Photo is inserted, adjusted, archived, or restored; each Viewer step instead observes the live projection order.

# Encapsulate Each Browsing Window in One Deep Module

The web client will implement each history entry's Browsing Window through one deep module that owns its collection and start anchor, cursor chain, Photo de-duplication, compact descriptors, incomplete row tail, Thumbnail Access leases, viewport demand, failures, and restoration anchor. Its small external interface exposes a subscribable read-only snapshot and browsing intents; it does not mutate routes. An owned album-browsing port at the internal network seam has an HTTP adapter for production and an in-memory adapter for tests, while Justified Row computation remains a pure internal seam. This concentrates ordering and race rules behind one test surface instead of requiring route elements to coordinate a cluster of shallow React hooks.

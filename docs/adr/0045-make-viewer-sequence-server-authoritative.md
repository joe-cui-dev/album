# Make Viewer Sequence Server-Authoritative

Photo Viewer Previous and Next navigation will use a server-authoritative Viewer Sequence scoped to the originating Timeline or Archive, rather than treating the Photos currently loaded by the browser as the complete sequence. Viewer history state retains the originating collection; a direct Viewer route infers it from the Photo's current Archive membership. The Viewer read contract will expose the live newer and older neighbours around the current Photo, while the client may use its loaded collection and prefetching to make navigation immediate. This adds a dedicated neighbour-read responsibility to the backend, but makes navigation correct across cursor boundaries, Jump to Date entry points, refreshes, direct URLs, and chronology changes without storing per-Viewer snapshots.

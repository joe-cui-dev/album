# Virtualize Justified Rows as Layout Items

Timeline and Archive will virtualise a vertical sequence whose items are month markers and completed Justified Rows, rather than individual Photos or whole months. A pure layout module will deterministically compose Photos into rows from container width, spacing, target height, and stored aspect ratios; a replaceable UI adapter will mount only nearby layout items with overscan. Active year/month state and restoration anchors will come from the virtualiser's visible-item model rather than observers attached to DOM nodes that may be recycled, and any row containing browser focus will remain mounted until focus moves. This preserves row geometry, testability, sticky navigation, and native Photo link focus while bounding rendered DOM for large months.

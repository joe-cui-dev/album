# Virtualize Justified Rows as Layout Items

Timeline and Archive will virtualise a vertical sequence whose items are month markers and completed Justified Rows, rather than individual Photos or whole months. A pure layout module will deterministically compose Photos into rows from container width, spacing, target height, and stored aspect ratios; a replaceable UI adapter will mount only nearby layout items with overscan. The adapter reports observed container width but does not own resize debouncing, reflow, or scroll correction. The Browsing Window ignores repeated observations of the same effective width, coalesces meaningful changes, recomputes layout, and restores the pre-reflow visible Photo anchor and relative row offset. Active year/month state and restoration anchors will come from the virtualiser's visible-item model rather than observers attached to DOM nodes that may be recycled. The UI adapter reports the library-neutral key of any row containing browser focus; that row remains mounted until focus moves and the Browsing Window includes it in active Thumbnail Access demand even when it is outside the viewport. This preserves row geometry, testability, sticky navigation, native Photo link focus, and its visible content while bounding rendered DOM for large months.
